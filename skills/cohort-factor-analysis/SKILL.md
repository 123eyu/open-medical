# 患者共性与危险因素挖掘

目标是给医生一份可复核的**探索性**分析：找出相关因素和值得进一步研究的线索，不是因果结论，也不是可直接发表的论文。

## 1. 把问题变成可分析的定义

从医生的话里明确以下几项，缺什么直接问，不要自己猜：
- **研究人群**：哪类患者（诊断关键词/ICD 编码、分组、标签、年龄段）。
- **比较方式**（二选一）：
  - 共性：目标人群 vs 其他在管患者（或指定对照组）；
  - 危险因素：人群内按某个**结局**分组（如 HbA1c 未达标、出现某并发症、某指标升高）。
- **结局定义**：用哪个检验项目、阈值、取哪次（最近一次 / 首次 / 随访期内最高）。
- **候选因素**：医生关心的，加上数据里覆盖率足够的人口学、诊断、用药、检验。

先调用 `research_data_dictionary`：
- 核对人群、结局和候选因素在本地数据里**是否存在、写法有几种**（如「HbA1c」「糖化血红蛋白」），覆盖了多少患者；
- 覆盖率低于约 30% 的变量不作为主要因素，可以作为补充说明；
- 估计样本量与事件数，按每个自变量至少约 10 个结局事件（EPV≥10）确定多因素模型最多放几个变量。数据明显不够时如实告诉医生，建议改为描述性分析，不要硬做回归。

## 2. 写分析计划，让医生确认后再看结局

在对话里列出简短计划：人群与对照的筛选条件、结局定义、候选因素清单及编码方式（连续 / 分类、单位统一方法）、缺失处理（默认完整病例分析并报告缺失比例）、统计方法、显著性标准（α=0.05，单因素筛查用 Benjamini–Hochberg FDR）。

**医生确认前不要运行涉及结局的分析。**可以先跑描述性统计（人数、覆盖率），帮助医生定口径。确认后计划就固定下来；之后要改口径须说明原因，并在报告里注明。

## 3. 用 research_analyze 分步执行

每次调用只做一件事，写清楚 purpose。沙箱里 `tables` 是长表，先在代码里整理成「一人一行」的宽表：

```python
labs = tables["labs"]
item = labs[labs["item"].str.contains("HbA1c|糖化血红蛋白", case=False, regex=True)]
last = item.sort_values("day").groupby("pid").tail(1).set_index("pid")["value"]
dx = tables["diagnoses"]
has_dm = set(dx[dx["name"].str.contains("糖尿病")]["pid"])
df = tables["patients"].set_index("pid")
df["hba1c_last"] = last
df["dm"] = df.index.isin(has_dm).astype(int)
```

建议顺序：
1. **队列构建与流程**：每一步筛选后剩多少人，结局的事件数。
2. **基线特征表（Table 1）**：连续变量给均值±标准差或中位数（四分位距），分类变量给 n(%)；组间比较连续变量用 Welch t 或 Mann–Whitney，分类变量用卡方或 Fisher；同时给出缺失人数。
3. **单因素筛查**：每个候选因素给效应量（OR 或均值差，带 95% CI）、原始 p 值和 FDR 校正后的 q 值（`statsmodels.stats.multitest.multipletests(method="fdr_bh")`）。
4. **多因素模型**：结局为二分类用 logistic 回归（`statsmodels.formula.api.logit`），有随访时间和事件用 Cox 回归（`lifelines.CoxPHFitter`）。变量来自临床判断加单因素筛查结果，数量受 EPV 限制；报告调整后 OR/HR、95% CI、样本量，检查共线性（VIF）和模型是否收敛。
5. **图**：需要时画森林图或分组箱线图（plt 画好就会自动保存为成果）。

规则：
- `result` 只放汇总统计量，不放逐人数据；
- 代码报错就读 log 修正后重试，不要换一个容易显著的口径绕过问题；
- 记下每次结果里的 `analysisNumber` 和 `dataSnapshot.hash`，写报告时要用。

## 4. 报告（待复核草稿）

用以下结构直接写在回答里：
1. **结论摘要**：2–4 条主要发现，每条带效应量、95% CI 和样本量。
2. **方法**：人群与对照定义、结局定义、变量口径、缺失处理、统计方法。
3. **结果**：队列流程、基线表、单因素表（含 q 值）、多因素表、图（引用成果名称）。
4. **局限**：单中心回顾性数据；只能说明相关、不能说明因果；可能的混杂与选择偏倚；缺失比例；共做了几项分析（多重比较）；记录口径不一致。
5. **下一步建议**：值得前瞻验证的假设、需要补充采集的变量、是否值得结合文献扩展（可接 research-direction-scouting）。
6. **出处**：数据快照哈希、分析序号、Python 和统计包版本。

不要写「证明」「导致」这类因果措辞；不显著不等于没有关联，结果显著也不等于有临床意义。不要根据分析结果修改患者档案或分组，除非医生另行明确要求，且仍要走提案流程。
